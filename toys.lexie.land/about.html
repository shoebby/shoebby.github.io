About VisunovOS

VisunovOS is a narrative game engine developed by Alexandria van Eekelen, a realm of Lexie.Land. Its goal is to bring interactive storycraft to the web in a manner that is accessible, playful, and fun!

What this means is no need for npm installs, no PHP, no dynamic page shenanigans; the entire website can be copied, edited, run locally, and doesn't exceed (as of now) 15 megabytes in size.

VOS is fundamentally a toolbox; something that contains a variety of intermingling, modifiable tools, inviting the addition of many more. In future versions this will be made more explicit, by making adding and the modification of tools possible from within the browser.

FAQ

What is VOS currently capable of?
This current version of VisunovOS (v0.00.kj.13.001) is very incomplete, you can't even save your works or overall progress yet!
We have been adding a variety tools and toys to it however, to learn and see where limits and challenges lie. After today's Try Outs we will start with the bones that'll make up the 1.0 version of VisunovOS.
Current tools include:

  • DivBRUSH - A drawing toy that lets you draw with divs, including the many different CSS stylings that can be applied to them!
  • Flippabook - Import and jostle around various different files on multiple pages, whether it be a zine, a comic, or a visual novel!
  • Recurse^3 - A binary tree fractal creator. Each branch is a div, and can be styled as such!
  • Sierpinskinator - Sierpinski-esque fractal generator, add points to create various clouds of self-similar structure!
  • Div-Sprouter - Proto-Recurse^3, see where the big boy hails from!
  • Pop-Up Collager - A toy to make collages out of pop-ups, with options to either display a blank page with injected HTML or a webpage of your choosing!
  • Poppy - The mascot of VisunovOS and your personal assistant. Albeit limited, her role in learning and playing with VisunovOS will grow with time!
  • Settings - Change some of VisunovOS's visuals to make it truly yours!
  • Spinny - The most-torqued OS of all time.
  • GuyMode - Need some guys?

How was VOS made?
VisunovOS is largely hand-written vanilla HTML, CSS, and JS. Some JavaScript libraries (like JQuery UI for draggable elements) are used as well, and of course all of this wouldn't be possible without knowledge hubs like the MDN docs, Stackoverflow, my webdev critters, and my wonderful partner.
